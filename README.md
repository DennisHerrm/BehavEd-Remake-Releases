# BehavEd-Remake – Downloads

Fertige Programme von **BehavEd-Remake**, einem Nachbau des ICARUS-Skripteditors
BehavEd (Jedi Academy SDK) mit 3D-Vorschau für Zwischensequenzen aus Jedi
Academy und Movie Duels.

## Installieren

1. Unter [Releases](https://github.com/DennisHerrm/BehavEd-Remake-Releases/releases/latest)
   das neueste `BehavEd-Remake-rcNNN.zip` herunterladen.
2. Entpacken und `BehavEd-Remake/behaved.exe` starten (Windows 10/11).
3. Unter **Paths** die Spielordner von Jedi Academy bzw. Movie Duels eintragen.

## Updates

Das Programm sieht beim Start selbst hier nach, ob es eine neuere Fassung gibt,
und zeigt dann unten in der Statuszeile einen grünen Hinweis. Ein Klick lädt und
installiert sie (File → *Check for updates…* sucht von Hand). Ein GitHub-Konto
ist dafür nicht nötig.

Dieses Repository enthält nur die fertigen Programme, keinen Quelltext.
